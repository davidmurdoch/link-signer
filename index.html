URL Signer & Verifier

This demo lets you sign links with an ECDSA-P256 private key and verify signed links with the corresponding public key.

Sign URL

Paste a private-key JWK and the URL you want to sign.

Verify URL

Checks the sig parameter using the public JWK below.

Keys are handled entirely in-browser via the Web Crypto API. Nothing is sent over the network.

We can use GitHub pages, with their built-in repo-access authentication, to restrict access to this page. However, we might want to consider only doing this on the server side so employees with access to this page can't steal the private key.
